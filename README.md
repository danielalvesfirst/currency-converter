## 🇺🇸 English / 🇬🇧 English

### About

**Currency Converter** is a application that converts values from foreign currencies to Brazilian Real (BRL).

The user enters an amount, selects a currency, and receives the converted value based on the exchange rate defined in the application.

### Supported currencies

* 🇺🇸 US Dollar (USD)
* 🇪🇺 Euro (EUR)
* 🇬🇧 Pound Sterling (GBP)

### Features

* Currency selection
* Amount input
* Conversion to Brazilian Real (BRL)
* Automatic currency formatting
* Display of the current exchange rate used by the application
* Input validation
* Error handling
* Responsive interface

### Technologies

* HTML5
* CSS3
* JavaScript

### Concepts practiced

This project was developed to practice:

* DOM manipulation
* JavaScript events
* Forms
* Functions
* Conditional logic
* Variables and constants
* Mathematical operations
* Input validation
* `toLocaleString()` for currency formatting
* CSS layouts and styling

### Running the project

Clone the repository:

```bash
git clone https://github.com/danielalvesfirst/currency-converter.git
```

Enter the project folder:

```bash
cd currency-converter
```

Then open `index.html` in your browser.

You can also use **Live Server** in VS Code for local development.

### Project structure

```text
currency-converter/
├── img/
│   ├── bg.png
│   ├── chevron-down.svg
│   └── logo.svg
├── index.html
├── script.js
└── styles.css
```

> **Note:** The exchange rates are defined directly in `script.js` and are not fetched from an external API (Yet).

## 🇧🇷 Português / 🇵🇹 Português

### Sobre

**Currency Converter** é uma aplicação para converter valores de moedas estrangeiras para o Real brasileiro (BRL).

O usuário informa um valor, seleciona uma moeda e recebe o resultado convertido com base na cotação definida na aplicação.

### Moedas disponíveis

* 🇺🇸 Dólar Americano (USD)
* 🇪🇺 Euro (EUR)
* 🇬🇧 Libra Esterlina (GBP)

### Funcionalidades

* Seleção de moeda
* Campo para informar o valor
* Conversão para Real brasileiro (BRL)
* Formatação automática da moeda
* Exibição da cotação utilizada pela aplicação
* Validação do valor informado
* Tratamento de erros
* Interface responsiva

### Tecnologias

* HTML5
* CSS3
* JavaScript

### Conceitos praticados

O projeto foi desenvolvido para praticar:

* Manipulação do DOM
* Eventos em JavaScript
* Formulários
* Funções
* Estruturas condicionais
* Variáveis e constantes
* Operações matemáticas
* Validação de entradas
* `toLocaleString()` para formatação de valores monetários
* Layouts e estilização com CSS
